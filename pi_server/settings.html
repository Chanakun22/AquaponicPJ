Water System Apply Now

Circulation Pump
เปิดหรือปิดปั๊มน้ำวนหลักของระบบ ใช้สำหรับให้น้ำไหลเวียนตาม loop ปกติของบ่อและรางปลูก
Auto Refill
เปิดให้ระบบตรวจลูกลอย/เซ็นเซอร์ระดับน้ำแล้วสั่งเติมน้ำอัตโนมัติเมื่อ sump ต่ำกว่าระดับที่กำหนด
เวลาสูงสุดที่อนุญาตให้ปั๊มเติมน้ำทำงานต่อเนื่อง ถ้าเกินค่านี้แล้วยังไม่ถึงระดับที่ควรได้ ระบบจะมองว่าเติมผิดปกติและเข้า alarm
Auto ให้ระบบเลือก route เอง, Fish Tank คือเติมผ่านตู้ปลา/ทาง overflow, Direct Sump คือเติมเข้าถังรวมตรง
Allow Direct Sump Fallback
ถ้าเปิดไว้ ระบบสามารถสลับไปเติมเข้าถังรวมตรงได้เมื่อ route ปกติใช้เวลานานเกินไปหรือ logic auto เห็นว่าควร fallback

Exhaust Fan Apply Now

คุมพัดลมระบายอากาศจากอุณหภูมิและความชื้นของ DHT หรือสั่ง manual ได้ทันทีจากหน้าเว็บ
Enable Fan Controller
ปิดไว้ถ้า relay/pin พัดลมยังไม่ได้ต่อจริง หรือยังไม่ต้องการให้ระบบคุมพัดลม
Auto Mode
ถ้าเปิดไว้ พัดลมจะตัดสินใจจากค่าอุณหภูมิ/ความชื้นอากาศ ถ้าปิดจะใช้ manual state ที่สั่งไว้แทน
to
พัดลมจะเริ่มทำงานเมื่ออุณหภูมิถึงค่า ON และจะยอมปิดเมื่อเย็นลงต่ำกว่าค่า OFF เพื่อทำ hysteresis
to
ถ้าความชื้นสูงเกินกว่าค่า ON ระบบจะเปิดพัดลม และจะค่อยปิดเมื่อความชื้นลดต่ำกว่าค่า OFF
