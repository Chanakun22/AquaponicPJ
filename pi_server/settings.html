ระบบน้ำ ส่งทันที

รวมค่าหลักของระบบน้ำทั้งหมดไว้ในการ์ดเดียว ทั้ง circulation, refill policy, fish-safe refill limit, route fallback, สถานะจริงจาก ESP32 และปุ่มสั่งงานทันที
Circulation Pump
เปิดหรือปิดปั๊มน้ำวนหลักของระบบ ใช้สำหรับให้น้ำไหลเวียนตาม loop ปกติของบ่อและรางปลูก
Auto Refill
เปิดให้ระบบตรวจลูกลอย/เซ็นเซอร์ระดับน้ำของถังผสม แล้วสั่งเติมน้ำอัตโนมัติเมื่อระดับต่ำกว่าที่กำหนด
Refill Policy
เวลาสูงสุดของรอบเติมรวม เวลาสูงสุดของรอบเติมรวม ถ้าเกินค่านี้แล้วยังไม่ถึงระดับที่ควรได้ ระบบจะเข้า alarm
ช่วงพักขั้นต่ำหลังเติมถังผสม ช่วงพักขั้นต่ำหลังเติมถังผสมจบรอบ เพื่อกันการเติมถี่เกินไป
จำกัดเวลาปั๊มเติมผ่านตู้ปลาในแต่ละรอบ จำกัดเวลาปั๊มเติมผ่านตู้ปลาในแต่ละรอบ เพื่อไม่ให้น้ำ overflow ไหลลงถังผสมมากเกินไป
ช่วงพักก่อนอนุญาต route ผ่านตู้ปลาอีกครั้ง ช่วงพักก่อนอนุญาตให้ใช้ route ผ่านตู้ปลาได้อีกครั้ง หลังหยุดเพราะครบเวลา หรือ overflow sensor ทำงาน
เส้นทางเติมน้ำ
`อัตโนมัติ` จะเลือกเติมผ่านตู้ปลาก่อน แล้วหยุดตามเวลา/overflow sensor ก่อนค่อยพิจารณา fallback, `ผ่านตู้ปลา` คือบังคับใช้เฉพาะ route นี้, `เข้าถังผสมตรง` คือเปิดโซลินอยด์เติมเข้าถังผสมทันที
อนุญาต fallback เข้าถังผสมตรง
ใช้ตอนเลือก `อัตโนมัติ` เท่านั้น ถ้าเปิดไว้ระบบจะยอม fallback ไปทางเข้าถังผสมตรงเมื่อรอบเติมผ่านตู้ปลาหยุดแล้ว แต่ถังผสมยังไม่ถึงระดับที่ต้องการ

พัดลมระบายอากาศ ส่งทันที

เปิดตัวควบคุมพัดลม
ปิดไว้ถ้า relay/pin พัดลมยังไม่ได้ต่อจริง หรือยังไม่ต้องการให้ระบบคุมพัดลม
โหมดอัตโนมัติ
ถ้าเปิดไว้ พัดลมจะตัดสินใจจากค่าอุณหภูมิ/ความชื้นอากาศ ถ้าปิดจะใช้ manual state ที่สั่งไว้แทน
to
