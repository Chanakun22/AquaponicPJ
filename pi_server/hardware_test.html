ขั้นที่ 3
กลับสู่สถานะปลอดภัยก่อนออก
ถ้ามีพฤติกรรมแปลกหรือจบการทดสอบ ให้กดหยุดอย่างปลอดภัยก่อนออกจากหน้านี้
ค่าเซ็นเซอร์ ทดสอบเอาต์พุต ทดสอบระบบน้ำ หยุดปลอดภัย บันทึกการทดสอบ
ใช้หน้านี้สำหรับทดสอบ ของที่ firmware รองรับจริงตอนนี้: อ่านเซ็นเซอร์, ทดสอบปั๊มโดส A/B, เปิดปิดไฟผ่านรีเลย์, และทดสอบระบบน้ำตาม flow ปัจจุบันของเส้นทางเติม, การเติมน้ำด้วยมือ, ปั๊มหมุนน้ำ, และ alarm.
ระหว่างทดสอบปั๊มโดส ระบบอัตโนมัติจะหยุดชั่วคราวและกลับมาทำงานเองหลังการทดสอบจบ. สำหรับ input น้ำในหน้านี้ให้ตีความตาม wiring ปัจจุบัน: `SUMP_LEVEL_LOW`, `SUMP_LEVEL_HIGH`, `FISH_TANK_OVERFLOW` เป็น Active LOW ดังนั้นค่า `LOW` หมายถึงเซ็นเซอร์ตัวนั้นกำลัง trigger อยู่.

พร้อม
Workflow ปัจจุบัน
หน้าทดสอบนี้ตั้งใจให้ตรงกับความสามารถปัจจุบันของ firmware: ไม่มีการทดสอบ water pump แบบเก่าแล้ว เพราะการไหลของน้ำตอนนี้วิ่งผ่าน state machine ของระบบน้ำ และใช้เซ็นเซอร์น้ำเป็นตัวตัดสินใจ
  1. กด `รีเฟรชค่าน้ำ` ก่อนทุกครั้ง เพื่อดึง config และ state ล่าสุดจาก Pi/ESP32
  2. ดูการ์ด `SUMP_LEVEL_LOW`, `SUMP_LEVEL_HIGH`, `FISH_TANK_OVERFLOW` ด้านล่าง โดย `LOW = trigger`, `HIGH = ปกติ`
  3. ค่อยทดสอบ `ปั๊มหมุนน้ำ`, `เติมน้ำอัตโนมัติ`, `เส้นทางหลัก`, และ `เติมน้ำด้วยมือ` ตามลำดับ
  4. จบงานหรือมีพฤติกรรมผิดปกติ ให้กด `หยุด output ที่กำลังทดสอบ` แล้วค่อยเปิด auto refill กลับเองเมื่อพร้อม
ถ้า `FISH_TANK_OVERFLOW` ขึ้นว่า `ไม่ได้ติดตั้ง` แปลว่าบอร์ดนี้ยังไม่มี overflow sensor ต่ออยู่ ไม่ใช่ว่า sensor ปกติ
