เริ่มตรงนี้

ทดสอบทีละส่วนแบบควบคุมความเสี่ยงได้ง่ายขึ้น

หน้านี้จัดลำดับใหม่ให้ผู้ใช้เริ่มจากการอ่านค่าเซ็นเซอร์และเช็กลำดับการทำงานก่อน แล้วค่อยไล่ไปทดสอบเอาต์พุตหรือระบบน้ำ พร้อมมีจุดหยุดอย่างปลอดภัยให้กลับมาที่ภาวะนิ่งได้เร็ว

ขั้นที่ 1
อ่านค่าปัจจุบันก่อน
ใช้เพื่อยืนยันว่าเซ็นเซอร์สดและ ESP ยังตอบสนองอยู่ก่อนสั่งรีเลย์หรือปั๊ม
ขั้นที่ 2
ทดสอบเอาต์พุตทีละตัว
เริ่มจาก A/B, ไฟ, พัดลม, เครื่องให้อาหาร แล้วดูผลในบันทึกการทดสอบทุกครั้ง
ขั้นที่ 3
กลับสู่สถานะปลอดภัยก่อนออก
ถ้ามีพฤติกรรมแปลกหรือจบการทดสอบ ให้กดหยุดอย่างปลอดภัยก่อนออกจากหน้านี้
ค่าเซ็นเซอร์ ทดสอบเอาต์พุต ทดสอบระบบน้ำ หยุดปลอดภัย บันทึกการทดสอบ
ใช้หน้านี้สำหรับทดสอบ ของที่ firmware รองรับจริงตอนนี้: อ่านเซ็นเซอร์, ทดสอบปั๊มโดส A/B, เปิดปิดไฟผ่านรีเลย์, และทดสอบ Water System ตาม flow ปัจจุบันของ Preferred Route, Manual Refill, Circulation Pump, และ Alarm.
ระหว่างทดสอบปั๊มโดส Automation จะหยุดชั่วคราวและกลับมาทำงานเองหลังการทดสอบจบ. สำหรับ input น้ำในหน้านี้ให้ตีความตาม wiring ปัจจุบัน: `SUMP_LEVEL_LOW`, `SUMP_LEVEL_HIGH`, `FISH_TANK_OVERFLOW` เป็น Active LOW ดังนั้นค่า `LOW` หมายถึงเซ็นเซอร์ตัวนั้นกำลัง trigger อยู่.

Workflow ปัจจุบัน
หน้าทดสอบนี้ตั้งใจให้ตรงกับความสามารถปัจจุบันของ firmware: ไม่มีการทดสอบ water pump แบบเก่าแล้ว เพราะ flow ของ Water System ตอนนี้วิ่งผ่าน state machine และใช้ water sensors เป็นตัวตัดสินใจ
  1. กด `รีเฟรชค่าน้ำ` ก่อนทุกครั้ง เพื่อดึง config และ state ล่าสุดจาก Pi/ESP32
  2. ดูการ์ด `SUMP_LEVEL_LOW`, `SUMP_LEVEL_HIGH`, `FISH_TANK_OVERFLOW` ด้านล่าง โดย `LOW = trigger`, `HIGH = ปกติ`
  3. ค่อยทดสอบ `Circulation Pump`, `Auto Refill`, `Preferred Route`, และ `Manual Refill` ตามลำดับ
  4. จบงานหรือมีพฤติกรรมผิดปกติ ให้กด `หยุด output ที่กำลังทดสอบ` แล้วค่อยเปิด `Auto Refill` กลับเองเมื่อพร้อม
ถ้า `FISH_TANK_OVERFLOW` ขึ้นว่า `Not Installed` แปลว่าบอร์ดนี้ยังไม่มี overflow sensor ต่ออยู่ ไม่ใช่ว่า sensor ปกติ
